# Siva & Geetha — Wedding Invitation

A responsive wedding invitation for Siva Prasad and Geetha Priya.

## View locally

Open `index.html` in a browser, or run:

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Publish

The included GitHub Pages workflow publishes the site when changes reach `main`.
In the repository settings, select **GitHub Actions** as the Pages source.

The invitation remains visible through August 23, 2026 in India Standard Time.
Starting at midnight on August 24, it displays a closed-invitation message.
